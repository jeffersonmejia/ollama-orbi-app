=== COMANDOS UTILES - ORBI APP (DOCKER STACK) ===

1. DESPLEGAR/ACTUALIZAR EL STACK:
   docker stack deploy -c docker-stack.yml orbi-stack

2. DETENER EL STACK:
   docker stack rm orbi-stack

3. VER SERVICIOS:
   docker service ls

4. VER LOGS:
   docker service logs -f orbi-stack_orbiapp
   docker service logs -f orbi-stack_postgres

5. RECONSTRUIR IMAGEN Y REDESPLIEGUE:
   docker build -t orbiapp:latest .
   docker stack deploy -c docker-stack.yml orbi-stack

6. CONTAR REGISTROS (con postgres expuesto en 5434):
   docker exec $(docker ps --filter "name=orbi-stack_postgres" --format "{{.ID}}") psql -U cruduser -d orbi_app -c "SELECT '  ' || t.tablename || ': ' || to_char(c.reltuples, 'FM999,999,999') || ' registros' AS linea FROM pg_tables t JOIN pg_class c ON c.relname = t.tablename WHERE t.schemaname='public' AND c.reltuples > 0 ORDER BY c.reltuples DESC;" -c "SELECT '  TOTAL: ' || to_char(SUM(c.reltuples), 'FM999,999,999') || ' registros' FROM pg_class c JOIN pg_tables t ON c.relname = t.tablename WHERE t.schemaname='public';"

7. GENERAR DATOS (necesitas publicar puerto 5434 temporalmente en docker-stack.yml):
   docker stack deploy -c docker-stack.yml orbi-stack
   dotnet run --project src/OrbiApp.DataGenerator -- --connection "Host=localhost;Port=5434;Database=orbi_app;Username=cruduser;Password=postgres" --records 1000000 --reset

8. RESTAURAR BACKUP:
   docker exec $(docker ps --filter "name=orbi-stack_postgres" --format "{{.ID}}") pg_restore -U cruduser -d orbi_app -c --if-exists /tmp/restore.dump
